# Local Agent Task Cards

本目录保存本项目的本地 agent 任务卡。它们不是独立程序，而是调度器派发任务时使用的职责说明、边界约束和验收清单。

入口：

- `scheduler.md`
- `data_pipeline_agent.md`
- `training_agent.md`
- `remote_harness_agent.md`
- `baseline_agent.md`
- `ttc_inference_agent.md`
- `evaluation_agent.md`
- `research_lead_agent.md`

完整阶段计划见仓库根目录 `TASK_WORKSHEET.md`。
